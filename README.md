# 大锄头

大锄头是一个面向老师的班级管理小工具集合。当前已经包含公共学生名单、学生座次安排、作业提交记录、成绩记录与分析几个基础模块。

## 当前功能

- 工具首页
  - 展示“大锄头”工具入口。
  - 支持当前班级切换。
- 班级和学生管理
  - 支持新建班级。
  - 支持维护班级名称、学年、学期。
  - 支持单个添加学生。
  - 支持批量导入学生名单。
  - 支持编辑学生姓名、学号和状态。
  - 支持导出当前班级学生名单。
- 公共学生名单
  - 学生名单按班级保存。
  - 座位、作业、成绩等工具共用同一份学生数据。
  - 学生管理只在“班级和学生管理”模块进行，其他工具只读取名单。
  - 当前阶段使用浏览器 `localStorage` 存储，后续可迁移到 SQLite 或其他数据库。
- 学生座次安排
  - 从当前班级公共学生名单读取学生。
  - 支持在工具内切换班级。
  - 支持导入座次文本、CSV、JSON。
  - 支持拖拽排座。
  - 支持调整座位行列。
  - 支持导出座次表。
  - 导入座次时遇到名单外学生，会提示先到“班级和学生管理”添加。
- 作业提交记录
  - 创建每日作业。
  - 使用下拉框记录学生提交状态。
  - 按周、月、学期汇总未交、迟交和按时提交比例。
  - 支持生成未交名单，便于复制到班级群。
- 学生成绩记录与分析
  - 维护班级科目，并支持停用科目标记。
  - 创建考试并录入学生各科成绩。
  - 支持粘贴 CSV/表格文本批量导入当前考试成绩。
  - 按科目保存成绩。
  - 生成学生成绩变化折线图。
  - 通过学生状态和科目状态标记学生转入、转出以及科目变化。

## 规划功能

- 认证与数据持久化
  - 登录认证。
  - 服务端数据库存储。
  - 家长只读查询能力。

## 项目架构

当前项目是一个轻量原生 Web 应用，没有引入前端构建工具。

```text
bighoe
├── index.html          # 工具首页
├── home.js             # 首页班级切换和概览逻辑
├── shared.js           # 公共数据层，管理班级和学生名单
├── students.html       # 班级和学生管理页面
├── students.js         # 班级和学生管理逻辑
├── seating.html        # 学生座次安排页面
├── app.js              # 座次安排工具逻辑
├── homework.html       # 作业提交记录页面
├── homework.js         # 作业记录和统计逻辑
├── grades.html         # 成绩记录分析页面
├── grades.js           # 成绩录入、科目和趋势分析逻辑
├── styles.css          # 全局样式
├── server.js           # Node.js 静态文件服务
├── Dockerfile          # Docker 镜像构建文件
└── docker-compose.yml  # Docker Compose 运行配置
```

### 数据设计

当前数据保存在浏览器 `localStorage` 中：

- `bighoe-shared-state-v1`
  - 保存班级列表、当前班级、公共学生名单。
- `bighoe-seat-plan-v1-{classId}`
  - 按班级保存座位行列和座位安排。
- `bighoe-homework-v1`
  - 保存作业任务、学生提交状态和统计数据。
- `bighoe-grades-v1`
  - 保存科目、考试和学生成绩。

这样可以先把“公共学生名单”这个核心结构跑通。后续接入服务端数据库时，作业和成绩工具可以继续复用同样的数据模型。

### 管理边界

- 班级和学生只在“班级和学生管理”模块维护。
- 学生座次、作业记录、成绩记录等业务工具只提供班级切换和业务操作。
- 如果业务工具导入的数据里出现名单外学生，需要先回到“班级和学生管理”补充学生，再继续操作。

## 本地运行

需要本机安装 Node.js。

```bash
node server.js
```

默认访问：

```text
http://127.0.0.1:5173/
```

也可以指定端口：

```bash
node server.js 8080
```

或使用环境变量：

```bash
PORT=8080 node server.js
```

Windows PowerShell：

```powershell
$env:PORT = "8080"
node server.js
```

## Docker 运行

### 使用 Docker

构建镜像：

```bash
docker build -t bighoe .
```

运行容器：

```bash
docker run --rm -p 5173:5173 bighoe
```

访问：

```text
http://127.0.0.1:5173/
```

### 使用 Docker Compose

启动：

```bash
docker compose up -d
```

查看日志：

```bash
docker compose logs -f
```

停止：

```bash
docker compose down
```

默认访问：

```text
http://127.0.0.1:5173/
```

## 开发说明

- 当前没有构建步骤，修改 HTML、CSS、JS 后刷新浏览器即可。
- 如果通过 Docker 运行，修改代码后需要重新构建镜像：

```bash
docker compose up -d --build
```

- 当前数据保存在浏览器中，更换浏览器或清理浏览器数据会导致本地数据消失。进入服务端数据库阶段后会解决这个问题。
